## 4. 동적 영역 — Figma 기반 재정의

> 의도서 기반 동적 영역(임팩트 스토리/투명성 KPI/파트너) 정의는 ADR-006으로 폐기. Figma에서 확인된 것만 기록.

### 4-0. 랜딩 KPI 데이터 (KpiSection)

랜딩 페이지 "한 해동안 만들어낸 변화" 섹션. 4개 지표가 운영자에 의해 정기 갱신되어야 한다.

| 지표 | 단위 | 현재 샘플 |
|---|---|---|
| 누적 봉사자 수 | 명 | 45,217+ |
| 누적 봉사 기간 | 기간 (년/월) | 38년 5개월 |
| 봉사활동 횟수 | 회 | 3,614+ |
| 도움을 주게 된 가정 수 | 개 | 80,257+ |

→ 의도서의 5개 KPI(봉사 횟수·참여 인원·권역별·예산·상담)와 다름. **Figma 4개로 확정**.


### 4-1. 쌀 나눔 소식 (`news`) — 게시판형

ArticleCard(`114:8164`) 12 variants로 구성.

- **필드 (소식_전체·소식_상세 시안 기반 확인)**:
  - 제목 (string, required) — 샘플: "한식 행사 쌀 화환 320kg으로 이웃과 함께 나누는 식구 공동체"
  - **카테고리 (enum 5개 확정)** — `전체` / `가족 치유` / `지역 봉사` / `환경 캠페인` / `쌀 나눔`. 의도서 §5.2의 3 카테고리가 살아있음 + `쌀 나눔` 추가. "보도자료"는 별도 카테고리 아니라 이미지 없는 카드의 그라디언트 placeholder 표시
  - **태그 (자유 입력)** — 사전 정의 enum 아님. 운영자가 자유 텍스트 입력. 같은 태그끼리 검색·필터링 가능 (확정 2026-05-26)
  - 대표 이미지 (image) — 없으면 보라 그라디언트 플레이스홀더 + 카테고리 텍스트
  - 발행일 (date) — 샘플 `2026.03.11`
  - 본문 (rich text) — 텍스트 + 이미지 블록 혼합
  - 태그 (해시태그, 다중) — 샘플 `#이웃관심`, `#쌀나눔`, `#자원봉사·소관위원회`
  - 좋아요 카운트 (int) — Heart 컴포넌트, 익명
- **목록 페이지 구성**:
  - 상단 페이지 도입 카피 (PageTitle)
  - Banner (Sow Good 안내 띠)
  - 피처드 큰 카드 1개 (FeaturedStoryCard)
  - "더 많은 소식" 섹션: CategoryTabs → 카드 그리드 3×3 → Pagination
- **상세 페이지 구성**:
  - 상단 Background + Banner
  - 카테고리 칩 + 제목 + 메타(작성일+좋아요) + 태그 + 본문 + 소셜 공유
  - 하단 "다른 소식 살펴보기" 관련 글 3개
  - 우하단 떠다니는 ScrollTopButton

### 4-2. 활동 스토리 (`stories`)

StoryCard(`44:1840`) 컴포넌트 존재. 별도 페이지 시안 미디자인 — 콘텐츠 모델은 *Figma 추가 시안 받은 뒤* 정의.

## 5. 사용자 인터랙션 — Figma 기반 (2026-05-26 확정)

- **좋아요 (Heart)**: 익명 토글 카운터. IP+세션 기반 1회 토글 (재누르면 -1). 로그인 없음.
- **카테고리 탭 필터**: 목록 페이지 — 탭 클릭으로 즉시 필터링. URL 쿼리 동기화.
- **페이지네이션**: 목록 — Prev / 페이지 번호 / Next. 페이지당 9개 (3×3 그리드).
- **소셜 공유**: 상세 본문 하단 — **카카오톡 / 페이스북 / 링크 복사** 3개 (확정).
- **태그 (해시태그)**: **자유 입력** (확정). 클릭 시 같은 태그 목록 페이지로 이동.
- **관련 글**: 상세 하단 — **카테고리·태그·최신 조합 점수**로 추천 (확정).
- **스크롤탑 버튼**: 상세 우하단 떠다님. 스크롤 일정 거리 이후 노출.
- **헤더 메뉴 인터랙션** (확정):
  - **랜딩/메인**: 스크롤스파이 — 페이지 스크롤 위치에 따라 4 메뉴 중 해당 섹션의 메뉴가 active로 자동 변경. 메뉴 클릭 시 해당 섹션 앵커 스크롤.
  - **소식 페이지 등 다른 페이지**: "활동 스토리" 메뉴가 active로 고정 (현재 위치 표시).
- **검색**: 헤더 아이콘만 표시 — *기능은 1차 런칭에 없음*. 추후 반영 (확정).
- **문의/연락 폼**: 1차 런칭 범위에 없음 (확정).

- ✅ 실제 봉사 현장 사진 (정제 안 돼도 OK), 구체적 숫자+사람 이야기, "~습니다"체, 넓은 여백, 모바일 우선
