## 특이사항 (모호·해석 필요)

1. **768 카드 컬럼 gap = 18 (지시문의 22 와 상충)** — List w648 에 카드 x0/x331 (313w) → gap 18, 우측 4px 미사용. 767 도 동일하게 18. 균등분할(justify-between) 시 22 가 되지만 Figma 원본 좌표는 **18 고정**. 라이브 검증은 18 기준, 단 648 균등분할 구현(22)도 디자이너 슬랙 범위로 해석 가능.
2. **페이지네이션 활성 색** — Pagenation 컴포넌트 기본값은 `#00ab89`(keycolor2) 이나 이 페이지 인스턴스는 `#501f7e` 로 오버라이드. 사이트 키컬러(보라) 기준 `#501f7e` 가 정답으로 보임.
3. **767 Contents 와 Footer 10.4px 겹침** — Figma 원본 자체 (마지막 60px 바닥 패딩 구간). 시각 영향 없음, 코드 강제 재현 불필요.
4. **Line 83 (hairline) 위치가 BP 마다 다름** — 768: 헤더 직하(배너 위). 375·767: 배너 하단. 767 은 w648 중앙만. 선 색상은 이미지 asset 이라 미확인 [확인 필요] (탭 보더와 같은 `#d1d5db` 추정).
5. **Featured 본문 클램프가 비정수 줄수** — max-h 768=80px(≈3.5줄)·모바일=88px(≈3.9줄), lh 22.4px 기준. 코드 구현 시 line-clamp 3(768)/4(모바일) 중 택일 해석 필요.
6. **768 배너 상하 패딩 비대칭** (상34/하51.6) — 콘텐츠 그룹이 정중앙이 아님. 라이브에선 수직 중앙 정렬(≈42.8)과 4px 이상 차이.
7. **탭 컴포넌트 비활성 언더라인 잔재** — opacity 0 의 `#00ab89` 2×2 박스가 비활성 탭에 존재 (렌더 안 됨, 무시).
8. **375 본문 카피 더미 차이** — 375/767 Featured 본문에 768 에 없는 문장 2개+빈 줄이 더 들어있음 (디자이너 더미 텍스트 차이, 데이터 스펙 아님).
