## 0. 가장 큰 원인 — stale dev 서버 (코드 아님, 운영 이슈)

`_next/image` 옵티마이저가 MinIO(`localhost:9000`) 이미지를 **HTTP 400 "url parameter is not allowed"** 로 차단 → ArticleGrid·소식 카드·상세 본문 이미지가 전부 빈 플레이스홀더로 렌더. **원인은 코드가 아니라 오래된 dev 서버 프로세스.** `next.config.ts` 는 이미 올바름(`dangerouslyAllowLocalIP: true` (dev) + `remotePatterns` 에 `localhost:9000`). dev 서버를 **재시작**하면 `_next/image` → 200, 이미지 정상 렌더.

→ **사용자가 본 "디자인과 다름" 의 상당 부분이 이 stale 서버로 추정.** 코드 수정 불필요. 운영 수칙: next.config 변경/이미지 깨짐 시 `pnpm dev` 재시작 (next.config 는 startup 에만 로드, HMR 안 됨).

## 2. 판단 명시 (Figma 정확값 부재 → 엔지니어 결정, 투명 기록)

- **ArticleGrid 카드 md(768/2열) aspect = `aspect-[278/300]`(portrait)**: Figma 768 2열의 카드별 정확 높이를 node 단위로 추출하지 않고, base(375 1열)와 동일 portrait 비율을 2열에 적용. lg(3열)는 기존 tall(425/337/381) 유지. 시각 검증으로 마조네리 자연스러움 확인.
- **소식 목록 1→2열 전환 = 448px**: Figma 375=1열·767=2열만 확정(중간 경계 아트보드 없음). familyfed(동일 디자이너)의 `min-[448px]` 채택.

## 3. 유지(미수정) — 근거

- **KPI·Story 사이드컬럼 = `wide:flex-row`(1440)**: 문서화된 의도(1024~1439 stacked, 1440↑ side). 1440·768 시각 정합 OK → 유지.
- **소식 목록 Featured Hero = `lg:grid-cols-2`(1024↑ 가로 2단, 하위 stacked)**: Figma 하위 BP featured 레이아웃이 모호하고 familyfed 에 featured 부재(레퍼런스 없음). 합리적 반응형이며 명확한 Figma 모순 없음 → 유지.
- **Partners 로고 `md:grid-cols-3 lg:flex`**: 768 시각 정합 OK → 유지.
