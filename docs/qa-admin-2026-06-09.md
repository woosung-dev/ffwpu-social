## 환경 셋업 중 발견 — AUTH_URL 로컬 포트 불일치 (수정)
- `.env.local` `AUTH_URL=http://localhost:3000` 인데 dev 는 `PORT=3100`. 미인증 `/admin` 접근 시 NextAuth 가 **3000 으로 리다이렉트** → 3000 은 타 앱 점유라 로컬 어드민 로그인 불가.
- 조치: 로컬 `.env.local` AUTH_URL→3100(+`AUTH_TRUST_HOST=true`). `.env.example` 에 "AUTH_URL 은 구동 포트와 일치" 가이드 추가(커밋). 배포 시엔 실도메인이라 무관.

## 발견·수정한 버그

### BUG-1 (HIGH) — 모든 어드민 폼의 클라 검증 침묵 실패 [수정 완료]
- 증상: 잘못된 입력(slug 형식·비번 규칙 등) 제출 시 인라인 에러가 **안 보이고** 콘솔로만 ZodError throw. 운영자는 "추가 눌렀는데 반응 없음"으로 인식.
- 루트코즈: `@hookform/resolvers@3.10` zodResolver 가 `error.errors`(Zod v3 API)를 Array 검사 후 없으면 re-throw. **Zod v4 는 issues 를 `error.issues` 에 담아 `.errors` 부재** → 필드 에러 미설정.
- 수정: `@hookform/resolvers` ^3.10→^5.4(Zod v4 지원). NewsEditor `useForm` input/output 타입 분리(`tags` `.default`). 검증: 카테고리 slug·계정 비번 → 인라인 에러 표시 + 콘솔 0. (commit df2bc88)

### BUG-2 (MEDIUM) — 카테고리 이름·활성 수정이 리스트에 즉시 반영 안 됨 [수정 완료]
- 증상: 수정 다이얼로그로 이름/활성 변경→저장→다이얼로그 닫힘(성공)인데 목록은 **리로드 전까지 옛 값**. DB 는 갱신됨.
- 루트코즈: `CategoryOrderList` remount key 가 `id:sortOrder` 만 → 이름/활성만 바뀌면 key 동일→내부 `useState(rows)` stale.
- 수정: rowsKey 에 `name`·`isActive` 추가. 검증: 수정 후 리로드 없이 즉시 반영. (commit 69c1266)
